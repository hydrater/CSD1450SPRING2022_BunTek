========================= GUIDE =======================
------------------------ FORMAT -----------------------
/x0|W yyyy
- Put '/' at the front for calling certain commands
- x is for calling legends to run commands (Refer)
- 0 is the function called for the button/choice
	effect (CAUTION!: WILL ONLY WORK FOR b and c!)
- 0 is also the type of color for the actor's name (a)
	{Possible colors: a(black), b(blue), g(green),}
	{	c(cyan), r(red), p(purple), y(yellow),}
	{	w(white)			      }
- |W is optional to be added in
	It is responsible to decide which Encounter it
	can go to (Currently only can be used with /b2)

	Adding it to any other commands does nothing

- yyyy is the string displayed in the text renderer
	[Exception: c, which finds the artifact type  ]
	[Exception: d, which finds the specific sprite]
------------------------ LEGENDS ----------------------
a: Actor Name
b: Button for Encounter (Please don't mix with Choice)
0 - Leave
1 - Create Reward Selection
2 - Go to new dialogue
3 - Heal player by half
4 - Heal player to full [Removes X stardust]
5 - Pick Up random artifact
c: Choice for Rewards (Please don't mix with Encounter)
d: Design for Background
0 - space
1 - cave
2 - artic mounts
3 - crystal caves
4 - rainforest
5 - volcano
6 - yggdrasil
e: Encounter Action (Exactly the same as button)
